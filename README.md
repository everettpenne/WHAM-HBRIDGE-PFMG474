# WHAM-SWITCH-PFMG474

Switching-supply application firmware for this PFM/HRTIM controller
family: phase-locked, table-driven multi-channel PWM generation, on an
STM32G474QET6.

This is the same firmware previously developed as
[WHAM-PFMG474-V4](https://github.com/everettpenne/WHAM-PFMG474-V4),
relocated (2026-09-09) to its own explicitly-named repo now that a
sibling project exists for a different application on the same
hardware: [WHAM-XREX-PFMG474](https://github.com/everettpenne/WHAM-XREX-PFMG474),
a closed-loop PID controller for the Transrex magnet supplies. See
[`AGENTS.md`](AGENTS.md) for the full orientation and
[`docs/changelog.txt`](docs/changelog.txt) for the dated history,
including everything inherited from the original repo.
